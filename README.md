# Employee Management System

A small C++ OOP project developed at the end of my first year
of university.

## Features

- Add employees
- Remove employees
- Update employee information
- Search employees by ID
- Sort employees
- Calculate payroll
- Display statistics

## OOP Concepts

- Encapsulation
- Inheritance
- Polymorphism
- Abstract classes

## Data Structures

- std::unordered_map
- std::vector

## Employee Types

- Manager
- Full-time employee
- Part-time employee

## Status

This is a learning project and is not intended
for production use.
